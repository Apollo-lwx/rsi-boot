## 追溯说明

本矩阵建立 **PRD 需求 -> Specs 章节 -> Plans 任务** 之间的映射关系，确保：
1. **无遗漏**：每个 PRD 定义的功能都有 Specs 设计和 Plans 任务覆盖
2. **可审计**：从任意方向可追溯（需求->设计->实现 / 任务->设计->需求）
3. **优先级对齐**：优先级以 PRD §4 MoSCoW 定义为唯一权威来源（Phase 1 = P0、Phase 2 = P1、Phase 3 = P2、Phase 4 = P3）
